## 데이터 분석의 과정
데이터 분석의 과정을 딱 잘라서 구분하기는 어렵지만, 저는 최소 3개의 단계로 구분할 수 있다고 봅니다.

- **수집(Collection):**<br>
어떤 데이터를 어떻게 수집할 것인지에 대한 단계입니다. 분석을 하다보면 더 많은 데이터가 필요한 상황이 나오곤 합니다.<br>
그러니 같은 실험을 여러 번 하고싶지 않다면, 자신의 목적을 고려한 실험 디자인과 가능한 한 많은 정보의 기록이 필요합니다.<br>
데이터의 충분한 양과 질이 확보되지 않는다면 분석이 의미가 없습니다. 그러므로 가장 중요한 단계라고 볼 수 있습니다.

- **처리(Processing):**<br>
수집한 데이터에서 필요한 정보만을 추출하고 가공하는 단계입니다.<br>
이를 위해서는 데이터의 구조를 파악하는 능력이 중요합니다. 데이터가 어떻게 기록되어 있는지, 그래서 어떤 형태로 가공할 것인지 고민해야 합니다.<br>
특히 생물 데이터는 0이 많거나(zero-inflated) 고차원(high dimentional)인 경우가 대다수입니다.
따라서 filtering을 통해 걸러내거나 PCA나 UMAP 등 차원축소법 등 여러 기법을 사용하는 단계라고 할 수 있습니다.

- **분석(Analysis):**<br>
데이터를 시각화하고 해석하는 단계입니다.<br>
표 형식으로는 데이터가 어떤 변수에 영향을 받아 어떤 양상으로 변화하고 있는지 알아내기 어렵습니다.<br>
그러니 2차원 혹은 3차원 그래프를 축이나 세부 매개 변수를 조정하면서 가독성이 좋은 그림을 그리는 과정이 필요합니다.<br>
또한 시각화 후에는 해석을 해야 합니다. 이미 알려진 지식들을 종합하여 나의 데이터를 설명하는 것이 핵심입니다.<br>
이러한 과정을 통해 사전에 설정한 가설을 자신의 데이터로 검증할 수 있습니다.

## 날씨 데이터의 특징
이번 활동에 사용할 날씨 데이터는 [기상자료개방포털](https://data.kma.go.kr/cmmn/main.do)에서 가져왔습니다.<br>
로그인만 한다면, 우리나라의 여러 지역의 기온, 강수량, 풍속 등의 기상 데이터와 특정 철새의 발견, 식물의 개화 정보를 다운로드하여 사용할 수 있습니다.<br>

저 역시 처음 데이터 분석을 배울 때는 날씨 데이터로 분석해보기도 했고, 무엇보다 날씨는 저희가 직접 몸으로 느끼는 것이니 그래프를 해석하기에도 쉽고 재밌더라고요.
그래서 이번에 저희 소모임에서도 날씨 데이터 분석을 수행해보려 합니다.<br>
